## Architecture (contract for all workers)

Everything lives in `Assets/LumenWave/`. Namespace `LumenWave` (editor: `LumenWave.EditorTools`).

| Area | Folder | Owner |
|---|---|---|
| Core contracts (math, rules, events, input, session, level format/runtime) | `Scripts/Runtime/Core`, `Input`, `Level/LevelData.cs`, `Level/LevelBuilder.cs`, `Level/LevelRuntime.cs` | orchestrator |
| Visuals: shaders, materials, post FX, camera rig, background/parallax, tile styling | `Shaders/`, `Scripts/Runtime/Visuals` | visuals worker |
| Player: Umbra controller, procedural rig + animation, scarf, light receiver hookup | `Scripts/Runtime/Player` | player worker |
| Light system: beams, area lights, occlusion, mirrors, prisms, mixing, receiver | `Scripts/Runtime/Light` | light worker |
| Sound powers + audio: echo/shield/pulse, synth, drone, SFX, beat music | `Scripts/Runtime/Sound` | sound worker |
| Enemies: Sentinel, Wisp (+1) | `Scripts/Runtime/Enemies` | enemies worker |
| Level entities (exit, checkpoint, thorns, crystal, hidden, tutorial) + level files + bot | `Scripts/Runtime/Level/*` (other files), `Resources/Levels/*.txt` | levels worker |
| UI: title, pause, settings, rebinding, HUD, credits, end screen | `Scripts/Runtime/UI` | UI worker |
| MALink OSC | `Scripts/Runtime/MALink` | MALink worker |
| Editor tools (setup, scene builder, build) | `Scripts/Editor` | orchestrator |
| Tests | `Tests/EditMode`, `Tests/PlayMode` | each worker adds own test file |

### Key contracts
- **Scenes** are generated by `LumenWave/Build All Levels` (`BuildScript`). Each scene contains only a `SceneBootstrap(kind, levelNumber)`. Everything else is built at runtime from code + `Resources/Levels/*.txt` (order in `Resources/Levels/index.txt`).
- **Hooks**: `SceneBootstrap.Booting(kind, level)` (camera, lights, volume, UI attach here), `LevelBuilder.PostBuild(ctx)`, `LevelBuilder.TileStyler`, `LevelRuntime.Loaded(rt)`, `GameSystems.Register(installer)` for persistent services, `GameEvents.*` for gameplay events.
- **Entities**: `[LevelEntity("type")] static GameObject Build(EntitySpec s, LevelContext ctx)` in any LumenWave assembly. Grid chars: `#` block, `=` ledge, `P` player, `E` exit, `C` checkpoint, `^` thorns, `S` sentinel, `W` wisp, `x` crystal, `h` hidden platform, `T` tutorial, `o` orb. Parametrised entities go in the 3rd section (`type x y key=value`).
- **Light**: per-channel `LightExposure` → `LightRules.Evaluate(exposure, BeatClock.Hot)` → `LightEffect`. Physics in `LightMath` (inverse square, Beer–Lambert, reflect, Schlick, mixing, prism).
- **Player**: `IPlayerBody` (Teleport, Velocity, Facing, Grounded, GravityScale, Commands), `PlayerHealth`, `Resonance`. Input via `ICommandSource` → `PlayerCommands` (human: `HumanCommandSource`; bot: scripted).
- **Layers**: Ground 8, Player 9, Shield 10, Mirror 11, Prism 12, Enemy 13, Bridge 14, Trigger 15, Hazard 16, Crystal 17 (`Layers`).
- **Materials**: `MaterialLibrary.Get/Create/Tinted(name)` loads `Resources/Materials/<name>.mat`, generated by `EditorTools.MaterialAssets.EnsureAll()` (one per `LumenWave/*` shader in `Assets/LumenWave/Shaders` + URP base mats).
- **Pulse**: `IPulseReceiver.OnPulse(origin, strength)`. **Respawn**: `IResettable.ResetState()`.

### Tooling
- `scripts/compile.ps1 [-Setup]` — batch compile (+ project setup). ~15 s.
- `scripts/test.ps1 -Platform EditMode|PlayMode|All [-Filter regex]`.
- `scripts/build.ps1` — scenes + Windows build + zip to `Release/`.
- `scripts/screenshot.ps1 [-Shots "level:x:y;..."]` — runs built player in screenshot mode → `Screenshots/`.
- All Unity runs are serialised via `.unitylock/`.
